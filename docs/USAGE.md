# 使用与排错

[返回产品主页](../README.md) · [部署指南](DEPLOYMENT.md)

## 筛选与统计

目录树来自已有任务的下载目录，父节点计数包含后代任务；它不是 NAS 文件管理器，不会枚举空目录。任务状态计数以当前服务器全部任务计算，各类可以重叠：

| 状态 | 判断方式 |
| --- | --- |
| 全部 | 当前实例所有任务 |
| 下载中 | 正在下载或等待下载 |
| 已暂停 | 任务已停止 |
| 已完成 | 选定内容下载进度达到 100%，含已暂停的完成任务 |
| 校验中 | 正在校验或等待校验 |
| 活动中 | 当前下载或上传速度大于零 |
| 未活动 | 当前没有上传、下载流量，包含空闲做种与暂停任务 |
| 错误 | daemon 报告任务错误 |

活动状态随刷新变化。底部的“限速”是全局上限，备用限速开启时优先显示备用值；单任务限速、带宽组及做种规则仍可进一步限制速度。统计来自 daemon 的 `session_stats`，不是浏览器自己累计。

## 使用与排错

- 拖动侧栏右边界调整宽度（200–460px），双击恢复 256px；聚焦边界后可用左右方向键调整，Home/End 到最小/最大宽度。左下只保留“设置”，统计在侧栏滚动区。
- 默认每页 50 条，可选 25/50/100/200/500、全部，或自定义 1–10,000 条，并记忆偏好。筛选、搜索、排序及每页数量变化回到第一页。分页基于已同步的任务列表，RPC 仍按增量刷新，不是服务端分页。
- 表头复选框只选中当前页；跨页选择会保留，选择条提示包含其他页或筛选外任务，批量操作对全部已选任务生效。点击“取消选择”可清空。
- 左侧选择状态，再按需叠加目录、标签和 Tracker；重复点击同一条件可以取消，分组摘要上的叉号清除此项，“清除全部筛选”恢复全部任务。
- 目录箭头只控制展开，目录名称控制筛选。目录树、标签和 Tracker 收起后仍显示当前条件。
- `/` 或 `Ctrl/Cmd+K` 搜索；任务行支持 Ctrl/Cmd 多选、Shift 连选、右键菜单；`Esc` 清除选择与详情。
- 删除确认默认保留文件。改目录、重命名与脚本设置作用于服务器上的实际数据和权限。
- **页面能打开但无法连接**：检查上游地址、9091 端口、RPC 启用状态、IP/主机名白名单、DSM 防火墙；容器不要填写 localhost。
- **401**：点击“登录 Transmission”填写 RPC 凭据；自动连接不绕过认证。**403**：查看 IP 白名单与代理来源。**421**：检查 RPC 主机名白名单是否允许自定义 URL 中的主机名，或使用可达且获允许的 NAS IP。**409** 会由客户端自动握手处理。
- **502 / 超时**：查看容器日志，核对上游协议和路径；代理不跟随重定向，请填写最终 RPC 地址。变更请求不会自动重发，先刷新确认实际结果。
- **静态资源 404**：确认 Web 目录中直接有 index.html 和 assets，并检查权限、缓存与 URL 尾部 `/`。
- **没有显示某项设置**：只展示当前 daemon 支持的字段。
- **旧版配置报多个上游**：只保留一个 JSON 条目，或改用 `TRANSMISSION_RPC_URL`；不存在自动选择第一台的行为。
