# 使用与排错

[返回产品主页](../README.md) · [部署指南](DEPLOYMENT.md)

## HTTP Basic 直接登录

原生 Web 替换版支持通过浏览器的 HTTP Basic 认证直接进入，例如在地址栏输入 `http://username:password@nas.example:9091/transmission/web/`。用户名和密码中的特殊字符需要分别做 URL 百分号编码，例如 `@` 写成 `%40`。

浏览器完成认证后，Cove 的同源 RPC 请求自动沿用认证，刷新后无需再填写 Cove 登录窗口。请求使用不含凭据的绝对地址，避免相对 fetch 继承页面凭据而失败；Cove 不另存 URL 中的密码，底栏只显示 RPC 地址。浏览器如果不接受 URL 内凭据，可使用其 Basic 登录提示；如果页面已打开但 RPC 返回 401，仍会显示 Cove 登录窗口。登录凭据不会由 Cove 自动复制给其他后端。

## 隐藏的后端切换

默认仍为单实例自动连接。需要更换当前浏览器的后端时，按住 **Shift 点击左下角“设置”**；未连接时也可打开。手机或键盘不便时，在当前 Web URL 后添加 `?backend=1`（已有查询参数时加 `&backend=1`）。使用完可从 URL 去掉此参数，避免刷新时再次打开弹窗。

填写完整 RPC 地址（如 `https://nas.example/transmission/rpc`）或同源代理路径（如 `/other-transmission/rpc`）。用户名 / 密码可选，不能嵌入 URL。点击“连接并切换”先验证新服务器；失败时保留原连接，成功后清空旧任务、详情、选择和会话缓存。只长期保存一个手动地址，不维护服务器列表。点击“恢复自动连接”清除覆盖地址和凭据，重新使用当前站点的默认连接。

服务器返回 401 时自动弹出登录窗口，验证成功后才保存凭据。凭据使用当前标签页的 sessionStorage 保存，并绑定当前 RPC 地址，刷新无需重新输入；不会写入长期 localStorage，也不会复用到其他后端。切换后端、恢复自动连接或认证失效时清除旧凭据。标签页会话结束后通常清除；浏览器的会话恢复功能可能恢复该会话。浏览器禁用存储时仅在页面内存中保持登录。

**开发版、Docker 和 Node 版**：默认连接当前主机的 Transmission；Shift 点击设置后可填写任意可达的 HTTP/HTTPS RPC 地址，路径以 `/rpc` 结尾。界面使用同源内置代理，无需修改环境变量、预登记远程地址或重启。每次请求只转发到当前浏览器选择的目标，不更改默认上游，也不影响其他浏览器；切换时不会复用旧服务器的凭据。地址等于默认上游时仍使用 `/api/rpc`，其他完整地址使用 `/api/remote-rpc`。远程地址中的 `localhost` 指代理所在主机，Docker 桥接模式中则指容器。

**原生覆盖版**：自动从当前 Web 地址推导 RPC，例如 `/transmission/web/` 对应 `/transmission/rpc`，不需要配置。纯静态文件没有内置代理，手动填写其他服务器时由浏览器直接请求；跨域不通时，在现有反向代理配置同源路径，再将该路径填入切换窗口，见[原生版远程连接](DEPLOYMENT.md#原生版远程连接)。

跨域时目标必须允许当前来源、`POST`、`Content-Type`、`Authorization`、`X-Transmission-Session-Id`，并暴露响应头 `X-Transmission-Session-Id`。原生 Transmission 未配置可用的 CORS 代理时，推荐在现有反向代理上配置同源路径；不要通过关闭 RPC 认证解决跨域。HTTPS 页面不能直接连接 HTTP 后端，但可以通过同源服务端代理连接。部署层附加的 CSP 也需允许指定目标。

## 筛选与统计

目录树来自已有任务的下载目录，父节点计数包含后代任务；它不是 NAS 文件管理器，不会枚举空目录。任务状态计数以当前服务器全部任务计算，各类可以重叠：

| 状态 | 判断方式 |
| --- | --- |
| 全部 | 当前实例所有任务 |
| 下载中 | 正在下载或等待下载 |
| 已暂停 | 任务已停止 |
| 已完成 | 选定内容下载进度达到 100%，含已暂停的完成任务 |
| 校验中 | 正在校验或等待校验 |
| 活动中 | 当前下载或上传速度大于零 |
| 做种中 | daemon 状态为做种中，包含零速和正在上传的任务；不含已暂停或等待做种 |
| 错误 | daemon 报告任务错误 |

活动状态随刷新变化。种子数和下载者数按“总数(活跃数)”显示，例如 `32(4)`、`1(0)`：总数取 Tracker 返回的最大值，括号内分别为正在向本机发送数据、正在从本机接收数据的连接数；未知总数显示 `—`，不影响活跃数显示。两类数据来自不同来源，刷新时间也可能不同。

底部下载、上传分别显示“当前速度 / 当前限速”。限速是全局上限，备用限速开启时优先显示备用值，否则显示常规上限或“不限速”；单任务限速、带宽组及做种规则仍可进一步限制速度。统计来自 daemon 的 `session_stats`，不是浏览器自己累计。

## 使用与排错

- 拖动侧栏右边界调整宽度（200–460px），双击恢复 256px；聚焦边界后可用左右方向键调整，Home/End 到最小/最大宽度。左下只保留“设置”，统计在侧栏滚动区。
- 默认每页 50 条，可选 25/50/100/200/500、全部，或自定义 1–10,000 条，并记忆偏好。筛选、搜索、排序及每页数量变化回到第一页。分页基于已同步的任务列表，RPC 仍按增量刷新，不是服务端分页。
- 表头复选框只选中当前页；跨页选择会保留，选择条提示包含其他页或筛选外任务，批量操作对全部已选任务生效。点击“取消选择”可清空。
- 左侧选择状态，再按需叠加目录、标签和 Tracker；重复点击同一条件可以取消，分组摘要上的叉号清除此项，“清除全部筛选”恢复全部任务。
- 目录分布每次进入或刷新页面均默认收起，不再读取旧的展开偏好；当前页面可手动展开。标签和 Tracker 仍记住展开状态。目录箭头只控制展开，目录名称控制筛选；收起分组后仍显示当前筛选条件。
- 校验、立即开始和通告统一放在工具栏的“更多”菜单中，选中任务后可操作。
- `/` 或 `Ctrl/Cmd+K` 搜索；任务行支持 Ctrl/Cmd 多选、Shift 连选、右键菜单；`Esc` 清除选择与详情。
- 删除确认默认保留文件。改目录、重命名与脚本设置作用于服务器上的实际数据和权限。
- **页面能打开但无法连接**：检查上游地址、9091 端口、RPC 启用状态、IP/主机名白名单、DSM 防火墙；普通桥接容器中的 localhost 指容器自身，一键脚本的 host 网络模式则指宿主机。
- **401**：自动弹出“登录 Transmission”，填写 RPC 凭据；取消后可点击登录入口重新打开。认证失败会清除已保存的登录，自动连接不绕过认证。**403**：查看 IP 白名单与代理来源。**421**：检查 RPC 主机名白名单是否允许自定义 URL 中的主机名，或使用可达且获允许的 NAS IP。**409** 会由客户端自动握手处理。
- **502 / 超时**：查看容器日志，核对上游协议和路径；代理不跟随重定向，请填写最终 RPC 地址。变更请求不会自动重发，先刷新确认实际结果。
- **静态资源 404**：确认 Web 目录中直接有 index.html 和 assets，并检查权限、缓存与 URL 尾部 `/`。
- **没有显示某项设置**：只展示当前 daemon 支持的字段。
- **旧版配置报多个上游**：只保留一个 JSON 条目，或改用 `TRANSMISSION_RPC_URL`；不存在自动选择第一台的行为。
